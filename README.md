# EPL Prediction System

Web-based Premier League match prediction system
using Random Forest and Logistic Regression.

## Tech Stack

- Backend: Go, Fiber v3, GORM
- Database: PostgreSQL
- Machine Learning: Python, FastAPI, Scikit-learn
- Frontend: React, TypeScript, Tailwind CSS
- Infrastructure: Docker

## Project Structure

- backend: REST API and business logic
- ml-service: Machine learning training and prediction
- frontend: Web application
- infra: Infrastructure configuration
- docs: Project documentation
- scripts: Development utilities

## Development Status

Currently under development.

## Research Scope

Premier League seasons:
2018/2019 - 2026/2027

Models:

- Random Forest
- Logistic Regression
